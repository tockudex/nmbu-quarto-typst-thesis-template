# Nmbu-thesis-template Format

Quarto and Typst thesis template following NMBU's guidelines.


## Installing

```bash
quarto use template tockudex/nmbu-quarto-typst-thesis-template
```

This will install the format extension and create an example qmd file that you can use as a starting place for your document.
